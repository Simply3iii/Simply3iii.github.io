A ten-person team built a conversational agent that answers questions using NHS Scotland
information. Under the hood it's retrieval-augmented: a fine-tuned LLaMA-3.1-8B model with
FAISS search over the NHS data.

I led the speech subteam, adding Whisper for spoken questions and text-to-speech for the
answers. I also ran the project board and wrote a lot of the technical documentation.
